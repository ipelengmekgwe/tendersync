# ADR-0010: Next.js for the dashboard

**Status:** Accepted (23 Oct 2026)

## Context

Faster UI iteration and the owner's prior Next.js experience; Plan.txt allows Next.js or Blazor.

## Decision

Next.js 15 App Router, TypeScript strict, Tailwind, shadcn/ui, TanStack Query, OpenAPI-generated client.

## Consequences

Two languages in the repo. Blazor remains an option if a single-language repo becomes preferable.
