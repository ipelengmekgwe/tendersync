# ADR-0011: Identity with JWT and roles

**Status:** Accepted (23 Oct 2026)

## Context

Self-contained role-based access as Plan.txt requires, no third-party dependency.

## Decision

ASP.NET Core Identity, JWT access tokens with refresh-token rotation, roles Admin / Reviewer / Viewer; the dashboard keeps tokens in httpOnly cookies via route handlers.

## Consequences

Entra ID or Clerk can be added later for SaaS.
